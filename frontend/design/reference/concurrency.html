State Machine Legend

  • RUNNING (0x01)
    Actively consuming core cycles, writing WAL, or executing ledger math.
  • WAITING (0x02)
    Parked on pthread condition variable or waiting for row mutex acquisition.
  • READY / IDLE (0x00)
    Worker thread warmed, idle in thread-pool ring buffer awaiting dispatch.
  • BLOCKED (0x04)
    Contention threshold exceeded (>350ms). Candidate for deadlock resolution.
